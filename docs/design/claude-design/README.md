# Claude Design, archived

The two Claude Design projects this app was designed in, exported on 2026-10-28 (Share → Export → Project HTML → Project archive), because Claude Design closes on 14 December 2026. Design work goes on in Artifacts: the design system is the Artifact "Content Spiel Design System", built from this repository's CSS.

- `cs-studio/`: the project "Content Spiel design system": CS Studio's screens (`Studio *.dc.html`), the setup wizard, the design system page, the handoff of 2026-10 (`design_handoff_cs_studio/`) and Photo·Spiel's design system it started from (`_ds/`).
- `demo-site/`: the project "Content Spiel demo site": the default theme's base and its blocks (`Theme Base.dc.html`, `Block*.dc.html`).

A page opens in a browser from this folder; it needs the `_ds/` folder beside it.

**Left out:** the project's uploads (86 screenshots of CS Studio from the design rounds and a PDF of round 1, 13.6 MB). They are in the owner's copy of the full export, not in this public repository; the app's own browser tests can take the screens again.

This is a record of how the design was reached, not the current design: where a page and the code disagree, the code (and the Design System Artifact, which is drawn from it) is right. `../cs-studio-handoff-v3/` is the earlier handoff the CS Studio rebuild was built from.
