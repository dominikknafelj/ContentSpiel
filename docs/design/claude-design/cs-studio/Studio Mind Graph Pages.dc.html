b Key, at 3× size Status follows one rule for every mark. Filled means live and dashed means draft. An outline with a centre dot means scheduled. A dot on the bottom-right corner means a live record has more to come: dim for unpublished changes, warn for a change scheduled. Warn means scheduled everywhere, here and in the status chip. A ring type is a filled type drawn inside a ring. Sizes are given at 1×.

c Legend as filter Each entry is a checkbox, so a click on the mark, the name or the count toggles it. Counts are what's on the site, not what's in view. Tags are shown off here: when a type is off, its name goes to text-meta and its nodes and their lines leave the graph. "All posts" goes on and off with Post types. Status isn't a filter. It's explained by a "Status" link that opens the key from b as a popover.
