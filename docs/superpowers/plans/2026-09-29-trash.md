# Trash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deleting a page, post or library image in CS Studio moves it to a trash it can be restored from, and the trash is emptied by hand or after a configurable retention period.

**Architecture:**
- **Soft-delete columns.** `pages`, `posts` and `media_assets` get `trashed_at`/`trashed_by_id` (plus `trash_root_id` on `pages`). There's no `default_scope`.
- **Hiding trashed rows.** They're filtered at the existing narrowing points: `AccessControl::Scoping`, `PublicSite::Paths` (a trashed record computes no URL, so saving it deletes its `public_paths` rows), and a handful of public and media queries. A guard test pins every one of those points.
- **Services.** Four services under `app/services/trash/` (`Move`, `Restore`, `Purge`, `Empty`) replace `Pages::Destroy`, `Posts::Destroy` and `Media::Destroy`. A daily job purges expired items.
- **CS Studio.** It gets a Trash screen, and the Delete buttons become "Move to trash" with an Undo link.

**Tech Stack:**
- Rails 8.1, Postgres 17 locally and 18 on CI, Mobility jsonb, closure_tree.
- Solid Queue recurring tasks (production), ViewComponent, Stimulus via importmap.
- Minitest with fixtures; system tests on Cuprite.

**Spec:** `docs/superpowers/specs/2026-09-29-trash-design.md`

## Global Constraints

**Scope and data**
- Trash covers pages, posts and library images only. Deleting a single block, a tag, a group, a user or a token stays permanent.
- No `default_scope` anywhere. Hiding trashed rows is done explicitly at the narrowing points (spec §5).
- Columns:
  - `trashed_at` (datetime, nullable, indexed);
  - `trashed_by_id` (FK to `users`, `on_delete: :nullify`);
  - `pages.trash_root_id` (FK to `pages`, `on_delete: :nullify`);
  - `site_settings.trash_retention_days` (integer, not null, default 30, ≥ 0; 0 = never).

**Writes, permissions and audit**
- Every write goes through an `ApplicationService` with both `authorize!(` and `record_event(` in `#call`; the service contract test enforces this.
- Audit actions: `page.trashed`, `post.trashed`, `media.trashed`, `page.restored`, `post.restored`, `media.restored`, `page.purged`, `post.purged`, `media.purged`.
- Permissions:
  - Moving, restoring or purging one item needs the item's delete right: `pages.delete` / `posts.delete` / (`media.manage` or uploader + `media.upload`).
  - The new `trash.empty` (label "Empty trash", area "Trash", action `:empty`), Admin only, empties everything and may purge any single trashed item.
- "Not found, not forbidden": a trashed record loaded by id anywhere outside the Trash screen answers 404 (or an MCP "not found").
- The public site answers **404** for a trashed page or post, not 410.

**UI and code conventions**
- No browser dialogs: `Admin::ConfirmDialogComponent` for every confirm.
- Never define a Ruby module named `Admin::Media` (a guard test exists).
- Match the codebase's comment density: long, load-bearing comments on non-obvious invariants.

**Process**
- Commits use conventional messages ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never skip hooks.
- Tests: `PARALLEL_WORKERS=1 bin/rails test ...` for runs, `bin/rails test:system` for system tests, plus `bin/rubocop`.

## Spec corrections (rulings made while planning, binding)

- **URL finder names.** Spec §5.2 names `Page.find_by_full_path` and a `cached_paths` column; both are gone. Routing runs through the `public_paths` table (`PublicPath`, `PublicSite::Paths`, `PublicSite::Resolver`, `PublicSite::Urls`), and this plan targets those names.
- **How URLs are freed and rebuilt.** Spec §4.1/§4.2's "delete / rebuild `public_paths`" happens through `PublicSite::Paths` itself:
  - `compute_path` returns nil for a trashed record, and `canonical_page` ignores listing blocks on trashed pages.
  - Saving a record whose `trashed_at` changed therefore deletes (on trash) or rebuilds (on restore) its rows through the existing model callbacks.
  - Nothing can resurrect a trashed record's URL: `rebuild!`, `sync_posts` and a page save elsewhere all go through the same code.
  - `PublicSite::Paths#write` with a nil path already deletes *all* of a record's rows for that locale, redirects included.
- **Restoring under a new parent** needs the same checks as `Pages::Move`: `pages.move` on the page, and `pages.create` under the target parent. It is refused when the target is the page itself or one of its own descendants.
- **Parent picker.** The restore picker is a server-rendered `<select>` of kept pages the actor may create pages under (`AccessControl.scope(actor, "pages.create", ...)`), not the link-target combobox. That combobox is gated on `pages.read` and embedded in the rich-text controller.
- **Images in the trash.** Restoring a page or post also restores every trashed library image its hero, blocks or bodies still reference, and lists them in the result. Otherwise a restored page could point at an image that's still in the trash. Moving an image to the trash is refused while a *kept* owner uses it, so this only ever concerns images trashed after their owner.
- **Branch purge.** Purging a page branch purges the page and **all** of its descendants, which must all be trashed; it's refused if any is kept. Descendants trashed separately earlier are part of the branch for purging, since their parent is going.
- **`trash.empty` includes single purges.** Holding `trash.empty` also permits purging any single trashed item. `Trash::Empty` and the job both reuse `Trash::Purge` this way; the job runs as the trusted nil actor on the `:system` channel.
- **Sibling rank** (`Page::TreeRanking`) counts kept siblings only, so "move to rank N" in the tree means rank N among the pages the editor can see.

## Review Focus

1. **Visible rank vs. hidden siblings.** An editor moves a page to rank 2 while a trashed sibling sits at rank 1. It lands second among the *visible* siblings (Task 2 test).
2. **Listed posts follow the listing page.** A trashed page that holds a post listing makes the posts it listed lose, or move, their canonical URL; restoring the page gives the URLs back (Task 5 and Task 6 tests).
3. **Images trashed after their page.** An image trashed after the page that uses it comes back when the page is restored, so the hero isn't broken (Task 6 test).
4. **Autosave into a trashed record.** A CS Studio tab still open on a page that someone else trashed autosaves and gets a 404; the save doesn't bring the page back to life (Task 3 test).
5. **A clash in one locale only.** A slug taken in `de` but free in `en` gets the `-2` suffix in `de` alone (Task 6 test).

```ruby
# db/migrate/20260929090100_grant_trash_empty_to_admin.rb
# Fresh installs get `trash.empty` from `AccessControl::Seeds` (Admin's
# `grants: :all` resolves against the live registry); this backfills an
# already-seeded Admin group, like `GrantMediaManageToBuiltInGroups`. Admin
# only (trash spec §6): emptying the trash is the one irreversible bulk action.
class GrantTrashEmptyToAdmin < ActiveRecord::Migration[8.1]
  def up
    admin_groups.find_each do |group|
      group.grants.find_or_create_by!(permission: "trash.empty") { |grant| grant.scope = {} }
    end
  end

  def down
    AccessControl::Grant.where(group: admin_groups, permission: "trash.empty", scope: {}).delete_all
  end

  private

  def admin_groups = AccessControl::Group.where(built_in: true, name: AccessControl::Seeds::ADMIN_NAME)
end
```

```ruby
# app/models/concerns/trashable.rb
# Soft delete for the three trashable models (trash spec §3). Deliberately no
# `default_scope`: every place that must hide trashed rows says so -- the
# narrowing points in `AccessControl::Scoping` and `PublicSite::Paths`, plus
# the queries listed in `test/integration/trash_visibility_test.rb`, which
# fails if one of them starts leaking. A `default_scope` would hide rows from
# closure_tree, uniqueness checks, associations and the Trash screen itself
# in ways that are hard to see and harder to undo.
module Trashable
  extend ActiveSupport::Concern

  included do
    belongs_to :trashed_by, class_name: "User", optional: true
    scope :kept, -> { where(trashed_at: nil) }
    scope :trashed, -> { where.not(trashed_at: nil) }
  end

  def trashed? = trashed_at.present?
end
```

```ruby
# Whether `value` is some other *kept* record's slug in `locale` within the
# same `localized_slug_scope`. Trashed records don't hold their slug (trash
# spec §2 "URLs: freed at once") -- a page rebuilt in the trashed one's place
# must be able to take its address, and `Trash::Restore` uses this same
# question to find a free `-2`, `-3` suffix instead.
def slug_taken?(locale, value)
  ::Mobility.with_locale(locale) do
    scope = self.class.i18n.where(slug: value).where(localized_slug_scope => public_send(localized_slug_scope))
    scope = scope.where(trashed_at: nil) if self.class.column_names.include?("trashed_at")
    scope = scope.where.not(id: id) if persisted?
    scope.exists?
  end
end
```

```ruby
# app/services/trash/item_permissions.rb
module Trash
  # The one permission rule for acting on a single trashable item (trash spec
  # §6): its ordinary delete right -- scopes included -- or, for an image,
  # `media.manage` / being its uploader (`Media::Ownership`). `trash.empty`
  # also allows purging (see `Trash::Purge`), never moving or restoring.
  module ItemPermissions
    include Media::Ownership

    private

    def item_refusal(record)
      case record
      when Page then "pages.delete" unless authorize!("pages.delete", record)
      when Post then "posts.delete" unless authorize!("posts.delete", record)
      when Media::Asset then "media.manage" unless authorize!("media.manage", record) || uploader_may_manage?(record)
      else raise ArgumentError, "#{record.class} can't go to the trash"
      end
    end
  end
end
```

```ruby
# app/services/trash/move.rb
module Trash
  # Moves a page (with its whole branch), a post or a library image to the
  # trash (trash spec §4.1). Nothing is deleted: the rows stay, flagged
  # `trashed_at`, so `Trash::Restore` is a column update. Saving the flag is
  # what frees the URLs -- `PublicSite::Paths` computes no path for a
  # trashed record, so the model callbacks delete its `public_paths` rows,
  # redirects included, and resync every post a trashed listing page gave a
  # URL (`Page#resync_listed_posts`).
  #
  # A branch is flagged with `update_all` first and the root saved last, so
  # the root's single `sync_subtree` pass sees every descendant already
  # trashed -- saving each page would re-walk the subtree once per page.
  class Move < ApplicationService
    include ItemPermissions

    def initialize(record, actor: Current.actor)
      @record = record
      @actor = actor
    end

    def call
      refused = item_refusal(@record)
      return denied(refused, @record) if refused
      return failure(@record, [ "It's already in the trash" ]) if @record.trashed?
      return failure(@record, [ "The homepage can't be moved to the trash" ]) if @record.is_a?(Page) && @record.root?
      return failure(@record, [ in_use_message ]) if @record.is_a?(Media::Asset) && @record.used_by_kept_owner?

      moved = @record.class.transaction do
        descendant_ids = @record.is_a?(Page) ? trash_descendants : []
        @record.update!(trashed_at: now, trashed_by: actor_user, **(@record.is_a?(Page) ? { trash_root_id: @record.id } : {}))
        record_event("#{event_prefix}.trashed", subject: @record, metadata: descendant_ids.any? ? { descendant_ids: } : {})
        true
      end
      moved ? success(@record) : failure(@record)
    end

    private

    def now = @now ||= Time.current

    def trash_descendants
      ids = @record.descendants.kept.pluck(:id)
      Page.where(id: ids).update_all(trashed_at: now, trashed_by_id: actor_user&.id, trash_root_id: @record.id, updated_at: now)
      ids
    end

    def event_prefix = { Page => "page", Post => "post", Media::Asset => "media" }.fetch(@record.class)

    def in_use_message
      # Reuse the "used on …" wording `Media::Destroy#in_use_message` builds,
      # limited to kept owners. Move that helper into
      # `Media::Asset#in_use_message(kept_only:)` so `Trash::Purge` (Task 7)
      # shares it once `Media::Destroy` is gone.
      @record.in_use_message(kept_only: true)
    end
  end
end
```

Move `Media::Destroy`'s private `in_use_message`/`place_of`/`describe` onto `Media::Asset#in_use_message(kept_only: false)`, which filters to `usages.by_kept_owner` when `kept_only`. `Media::Destroy` calls the moved method until Task 7 deletes it. If `update!` raises `ActiveRecord::RecordInvalid`, rescue it and return `failure(@record)`.

```ruby
  # is checked against kept records first and moved to the first free
  # `-2`, `-3`, … suffix when taken (`#slug_changes` reports them). Images
  # the record still references that went to the trash after it come back
  # too (`#restored_assets`) -- a restored page must never point at a
  # trashed image.
  #
  # A page trashed as part of someone else's branch comes back only with
  # its root, or on its own under a new `parent:` -- which needs what
  # `Pages::Move` needs: `pages.move` on the page and `pages.create` under
  # the target.
  class Restore < ApplicationService
    include ItemPermissions

    attr_reader :slug_changes, :restored_assets

    def initialize(record, parent: nil, actor: Current.actor)
      @record, @parent, @actor = record, parent, actor
      @slug_changes = []
      @restored_assets = []
    end

    def call
      refused = item_refusal(@record)
      return denied(refused, @record) if refused
      return failure(@record, [ "It isn't in the trash" ]) unless @record.trashed?
      if @record.is_a?(Page)
        problem = page_problem
        return problem if problem
      end

      restored = @record.class.transaction do
        branch_ids = @record.is_a?(Page) ? restore_branch_members : []
        move_under_new_parent if @parent
        free_slugs(@record)
        @record.assign_attributes(trashed_at: nil, trashed_by: nil, **(@record.is_a?(Page) ? { trash_root_id: nil } : {}))
        @record.save || raise(ActiveRecord::Rollback)
        restore_referenced_assets(branch_ids)
        record_event("#{event_prefix}.restored", subject: @record, metadata: event_metadata)
        true
      end
      restored ? success(@record) : failure(@record)
    end

    private

    def page_problem
      if @parent
        return denied("pages.move", @record) unless authorize!("pages.move", @record)
        return denied("pages.create", @record) unless may_create_under_target?
        return failure(@record, [ "Choose a page that isn't in the trash" ]) if @parent.trashed?
        return failure(@record, [ "A page can't be restored under itself or one of its own subpages" ]) if @parent.self_and_ancestors.include?(@record)
      elsif @record.parent_id.nil? || !Page.exists?(@record.parent_id)
        return failure(@record, [ "Its parent page no longer exists: choose a new parent" ])
      elsif @record.trash_root_id != @record.id
        root = Page.find_by(id: @record.trash_root_id)
        return failure(@record, [ "Restore “#{root&.title}” to bring this page back, or choose a new parent" ])
      elsif @record.parent.trashed?
        return failure(@record, [ "Its parent page is in the trash: restore that first, or choose a new parent" ])
      end
      nil
    end

    # Same check-then-put-back as `Pages::Move#may_create_under_target?`.
    def may_create_under_target?
      original = @record.parent
      @record.parent = @parent
      authorize!("pages.create", @record)
    ensure
      @record.parent = original
    end

    def restore_branch_members
      ids = Page.where(trash_root_id: @record.id).where.not(id: @record.id).pluck(:id)
      Page.where(id: ids).update_all(trashed_at: nil, trashed_by_id: nil, trash_root_id: nil, updated_at: Time.current)
      ids
    end

    # Rejoins at the end of its new siblings (`Page::TreeRanking` ranks kept
    # siblings only, Task 2).
    def move_under_new_parent
      @record.parent = @parent
      @record.position = Page.kept.where(parent_id: @parent.id).maximum(:position).to_i + 1
    end

    def free_slugs(record)
      Locales.enabled.each do |locale|
        accessor = Mobility.normalize_locale_accessor(:slug, locale)
        original = record.public_send(accessor)
        next if original.blank? || !record.slug_taken?(locale, original)

        candidate = (2..).lazy.map { |n| "#{original}-#{n}" }.find { |slug| !record.slug_taken?(locale, slug) }
        record.public_send("#{accessor}=", candidate)
        @slug_changes << { record:, locale: locale.to_s, from: original, to: candidate }
      end
    end

    def restore_referenced_assets(branch_ids)
      owners = owners_for_assets(branch_ids)
      ids = owners.flat_map { |type, owner_ids| Media::Usage.where(owner_type: type, owner_id: owner_ids).pluck(:media_asset_id) }.uniq
      @restored_assets = Media::Asset.trashed.where(id: ids).to_a
      Media::Asset.where(id: @restored_assets.map(&:id)).update_all(trashed_at: nil, trashed_by_id: nil, updated_at: Time.current)
    end

    def owners_for_assets(branch_ids)
      case @record
      when Page
        page_ids = [ @record.id, *branch_ids ]
        { "Page" => page_ids, "ContentBlock" => ContentBlock.where(owner_type: "Page", owner_id: page_ids).pluck(:id) }
      when Post
        { "Post" => [ @record.id ], "ContentBlock" => ContentBlock.where(owner: @record).pluck(:id) }
      else {}
      end
    end

    def event_prefix = { Page => "page", Post => "post", Media::Asset => "media" }.fetch(@record.class)

    def event_metadata
      {
        slug_changes: @slug_changes.map { |c| c.except(:record).merge(record: "#{c[:record].class.name}##{c[:record].id}") },
        restored_asset_ids: @restored_assets.map(&:id)
      }.compact_blank
    end
  end
end
```

Restoring an image doesn't touch slugs: `free_slugs` returns early when the record doesn't respond to `slug_taken?`. Guard it with `return unless record.respond_to?(:slug_taken?)`.

```ruby
# app/services/trash/purge.rb
module Trash
  # Deletes a trashed item for good (trash spec §4.3) -- the permanent
  # delete that `Pages::Destroy`/`Posts::Destroy`/`Media::Destroy` used to
  # be, now only reachable from the trash. Allowed by the item's own delete
  # right or by `trash.empty` (which is how `Trash::Empty` and the retention
  # job reach it).
  #
  # A page takes its whole subtree, deepest first; every page in it must be
  # trashed (a kept one means someone restored it under this page's branch,
  # which `Trash::Restore` can't do -- so this is a guard, not a flow).
  # `Page#ensure_no_children` still runs on each destroy and passes because
  # children go first. An image goes only once *no* usage row points at it,
  # a trashed owner's included -- `Media::Asset#used?`, not
  # `#used_by_kept_owner?` -- and the FK on `media_usages` backs that up.
  class Purge < ApplicationService
    include ItemPermissions

    def initialize(record, actor: Current.actor)
      @record, @actor = record, actor
    end

    def call
      refused = item_refusal(@record)
      if refused && !authorize!("trash.empty", nil)
        return denied(refused, @record)
      end
      return failure(@record, [ "Only items in the trash can be deleted permanently" ]) unless @record.trashed?

      purged = @record.class.transaction(requires_new: true) do
        record_event("#{event_prefix}.purged", subject: @record)
        case @record
        when Page then purge_branch
        when Post then purge_post
        when Media::Asset then purge_asset
        end
      end
      purged ? success(@record) : failure(@record)
    rescue ActiveRecord::InvalidForeignKey
      failure(@record, [ @record.is_a?(Media::Asset) ? @record.in_use_message : "Something still refers to it" ])
    end

    private

    def purge_branch
      pages = @record.self_and_descendants.to_a
      if pages.any? { |page| !page.trashed? }
        @record.errors.add(:base, "A page under it isn't in the trash")
        raise ActiveRecord::Rollback
      end
      pages.sort_by { |page| -page.depth }.each do |page|
        blocks = page.content_blocks.to_a
        page.destroy || raise(ActiveRecord::Rollback)
        [ page, *blocks ].each { |owner| Media::UsageIndex.refresh(owner) }
      end
      true
    end

    def purge_post
      @record.destroy || raise(ActiveRecord::Rollback)
      Media::UsageIndex.refresh(@record)
      true
    end

    def purge_asset
      if @record.used?
        @record.errors.add(:base, @record.in_use_message)
        raise ActiveRecord::Rollback
      end
      @record.destroy || raise(ActiveRecord::Rollback)
      true
    end

    def event_prefix = { Page => "page", Post => "post", Media::Asset => "media" }.fetch(@record.class)
  end
end
```

```ruby
# app/services/trash/empty.rb
module Trash
  # Empties the whole trash (trash spec §4.4), Admin only (`trash.empty`).
  # Each item goes through `Trash::Purge` in `Trash.roots` order, each in
  # its own savepoint, so one item that can't go (an image something kept
  # still uses) is skipped and reported, never aborting the rest. One
  # `trash.emptied` event summarises the run; every purge records its own.
  class Empty < ApplicationService
    attr_reader :purged_count, :skipped

    def initialize(actor: Current.actor)
      @actor = actor
      @purged_count = 0
      @skipped = []
    end

    def call
      return denied("trash.empty", nil) unless authorize!("trash.empty", nil)

      Trash.each_root do |record|
        result = Purge.call(record, actor: @actor)
        result.ok? ? @purged_count += 1 : @skipped << { record:, errors: result.errors }
      end
      record_event("trash.emptied", metadata: { purged: @purged_count, skipped: @skipped.size })
      success(nil)
    end
  end
end
```

```ruby
# app/jobs/trash/purge_expired_job.rb
module Trash
  # Daily (config/recurring.yml): permanently deletes what's been in the
  # trash longer than `SiteSetting#trash_retention_days` (trash spec §4.4);
  # 0 means never. A page branch goes by its root's `trashed_at` -- the
  # moment an editor trashed it -- since `Trash.roots` lists roots only.
  #
  # Runs as the trusted nil actor on the `:system` channel, so its
  # `*.purged` events read "System" in the audit log and `Trash::Purge`'s
  # authorization passes the way it does for any trusted code path. Each item
  # purges in its own savepoint (`Trash::Purge`); one that can't go is logged
  # and skipped.
  class PurgeExpiredJob < ApplicationJob
    queue_as :default

    def perform
      days = SiteSetting.instance.trash_retention_days
      return if days.zero?

      cutoff = days.days.ago
      Current.set(actor: nil, channel: :system) do
        Trash.roots.each_value do |relation|
          relation.where(trashed_at: ...cutoff).find_each do |record|
            result = Purge.call(record, actor: nil)
            Rails.logger.info("[trash] kept #{record.class.name}##{record.id}: #{result.errors.to_sentence}") unless result.ok?
          end
        end
      end
    end
  end
end
```

Controller outline:

```ruby
module Admin
  # The Trash screen (trash spec §7): everything the viewer could restore,
  # newest first, ~50 per page with the Media module's `limit(N+1)` paging.
  # Items are loaded only through `AccessControl.scope(..., trashed: true)`
  # (pages and posts, so scoped delete rights narrow the list) or
  # `Media::Asset.trashed` filtered by the same rule `Trash::ItemPermissions`
  # applies -- an id the viewer can't act on is "not found", never
  # "forbidden".
  class TrashController < BaseController
    PER_PAGE = 50
    MODELS = { "page" => Page, "post" => Post, "media" => Media::Asset }.freeze

    before_action :require_trash_access
    before_action :set_item, only: %i[restore purge]

    def index
      @type = params[:type].presence_in(MODELS.keys)
      @offset = params[:offset].to_i
      @items = listed_items   # an Array of records, newest trashed_at first, PER_PAGE + 1
      @has_next = @items.size > PER_PAGE
      @items = @items.first(PER_PAGE)
      @retention_days = Current.site.trash_retention_days
      @parent_choices = AccessControl.scope(Current.actor, "pages.create", Page.all).order(:id)  # for the parent <select>
    end

    def restore
      service = Trash::Restore.new(@item, parent: chosen_parent)
      result = service.call
      return forbidden_or(result) { redirect_to admin_trash_path, alert: result.errors.to_sentence } unless result.ok?
      redirect_to admin_trash_path, notice: restored_notice(service), status: :see_other
    end

    def purge
      result = Trash::Purge.call(@item)
      return forbidden_or(result) { redirect_to admin_trash_path, alert: result.errors.to_sentence } unless result.ok?
      redirect_to admin_trash_path, notice: "Deleted “#{title_of(@item)}” permanently", status: :see_other
    end

    def empty
      service = Trash::Empty.new
      result = service.call
      return forbidden_or(result) { redirect_to admin_trash_path } unless result.ok?
      notice = "Emptied the trash: #{service.purged_count} deleted permanently"
      notice += ", #{service.skipped.size} kept (still in use)" if service.skipped.any?
      redirect_to admin_trash_path, notice:, status: :see_other
    end
    # private: require_trash_access (any of the Trash module's keys, else 403),
    # set_item (MODELS.fetch(type) through the trashed scope; else 404),
    # listed_items, chosen_parent (Page.kept.find_by(id: params[:parent_id])),
    # restored_notice ("Restored “About”" + " as about-2 (the URL was taken)" per slug change
    # + " and 1 image" when images came back), title_of.
  end
end
```

`listed_items` merges the three sources in Ruby: take up to `PER_PAGE + 1 + offset` from each ordered relation, sort by `trashed_at` desc, then slice. For pages, list only branch roots (`trash_root_id = id`); a separately trashed descendant inside a trashed branch is still its own root. The subpage count is `Page.where(trash_root_id: root.id).where.not(id: root.id).count`, preloaded with one `group(:trash_root_id).count`. Images: kept only if `authorize!`-equivalent `can?("media.manage", asset) || asset.created_by_id == Current.user&.id && can?("media.upload")`.

Row component: title (thumbnail for images), type label, "Trashed by NAME" (or "Trashed by someone who has since left" when `trashed_by` is nil), a relative time, and "Deleted permanently in N days" (`retention - days since trashed_at`, at least 0; hidden when retention is 0).
- **Pages:** "+N subpages", expandable with `<details>`, listing their titles.
- **Restore:** a `button_to` POST. When `@item` is a page that needs a parent (its `trash_root_id` isn't its own id, or its parent is trashed or missing), it's a small form with a `<select name="parent_id">` of `@parent_choices` instead.
- **Delete permanently:** opens `Admin::ConfirmDialogComponent` ("Delete permanently?", body "This can't be undone."). For an image with `used?`, the button is disabled, with the title "Still used by an item in the trash".
- **Empty trash:** above the list, rendered when `can?("trash.empty")`, with a confirm dialog "Empty the trash?" and the body "N items will be deleted permanently. This can't be undone."

`FlashComponent` renders the existing `role="status"`/`role="alert"` paragraphs plus the optional `button_to action[:label], action[:url], method: action[:method]`. Use it on the Trash screen.

Sidebar: add `{ label: "Trash", path: :admin_trash_path, permission: %w[pages.delete posts.delete media.manage media.upload trash.empty] }` (match the real entry keys) after Media. Change `admin_modules` to `Array(e[:permission]).any? { |key| can?(key) }` for arrays and keep `nil` meaning always. `require_trash_access` uses the same list (403 when none is held, like `require_permission`).
