# CS Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build CS Studio, ContentSpiel's own admin at a configurable path (default `/cs-studio`). It is a three-column Hotwire shell (modules | page tree | content) with autosaving page, block, post and tag editing in every enabled language. It replaces Avo for everyday content work.

**Architecture:**
- **Controllers:** `Admin::*` controllers under an `ADMIN_PATH` route scope, inheriting `Admin::BaseController`. They write only through the existing services (`Pages::*`, `ContentBlocks::*`, `Posts::Save`, plus new `Tags::*`).
- **Screens:** server-rendered with view components (`app/components/admin/`). Field components are generated from `ContentModel` field schemas.
- **Client side:** Turbo Frames swap the tree and content columns; Stimulus controllers autosave each form (debounced PATCH), answered with Turbo Streams; SortableJS (already pinned) handles drag and drop.

**Tech Stack:** Rails 8.1, Hotwire (Turbo 8, Stimulus), importmap (no npm), SortableJS (`pin "sortablejs"` exists), ViewComponent + Lookbook, Tailwind v4 product build (`--cs-*` tokens), ActionText/Trix, Minitest + Capybara (headless Chrome).

**Spec:** `docs/superpowers/specs/2026-09-27-cs-studio-design.md` (binding). Background:
- `docs/superpowers/specs/2026-09-26-foundations-design.md` (services, Urls, preview, Locales);
- `docs/superpowers/specs/2026-09-27-open-types-design.md` (registries, FieldSet, components).

## Global Constraints

- **Admin path.** Read once at boot: `ContentSpiel::ADMIN_PATH = ENV.fetch("ADMIN_PATH", "cs-studio")`.
  - It must be one URL-safe segment (`/\A[a-z0-9][a-z0-9_-]*\z/`); otherwise boot raises.
  - Every admin route is inside `scope ContentSpiel::ADMIN_PATH, module: :admin, as: :admin`, declared before `/preview` and the public catch-alls. `Setup::RedirectConstraint` stays first.
- **Sign-in** lives at `/<ADMIN_PATH>/sign-in` and **password reset** at `/<ADMIN_PATH>/password`. The public `/session` and `/passwords` routes are removed.
- **Writes** go only through services, which return `ApplicationService::Result`. Controllers turn per-field errors into Turbo Stream error messages.
- **`Current.channel = :admin`** in `Admin::BaseController`; `authorize!` is a no-op hook.
- **Editing locale** comes from `?locale=`, validated against `Locales.enabled`, falling back to `Locales.default`.
  - Translated values go to `translations: { locale => {...} }`, untranslated ones to `attributes:`.
  - In a non-default locale each translatable input shows the `Locales.default` value read-only, plus an empty `data-translate-slot` element.
- **Autosave:** debounced 1000 ms after the last input, immediate on blur, one in-flight request per form (the latest queued), 3 retries with backoff. The status texts are exactly:
  - `Saving…`
  - `Saved HH:MM`
  - `Couldn't save — N problems`
  - `Not saved — retrying`
  - `Not saved — check your connection`
  - `Changed elsewhere — reload to see the latest`
  - on published content, the header note `Live — changes appear on the site as you edit`.
- **Known interim states** (spec §7, already in `docs/roadmap.md`): autosave writes straight to the record, Avo stays mounted, and deletes are permanent. Don't build workarounds for them.
- **UI:**
  - product tokens and the product Tailwind build (`app/assets/tailwind/application.css`), with `@source` entries for `app/components/admin` and `app/views/admin`;
  - no public-theme (`--th-*`) classes in the admin;
  - every admin view component has a Lookbook preview under `test/components/previews/admin/`.
- **JS:** Stimulus controllers in `app/javascript/controllers/admin/` (identifiers `admin--*`); no npm, and pin anything new with `bin/importmap pin`.
- **Existing rules still apply:**
  - public URLs only through `PublicSite::Urls`;
  - public text through `Locales.read`;
  - no new integer enums;
  - no Page/Post fixtures (use `test/support/content_helper.rb`: `root_page`, `create_page`, `create_post`, `with_locales`);
  - test-only types use `test/…` names and `with_test_types` (`test/support/test_types.rb`).
- **Comments:** long, load-bearing ones are the norm (CLAUDE.md).
- **Tests:** `PARALLEL_WORKERS=1 bin/rails test`; `bin/rails test test/system` alone; system tests use scripted clicks (see the `press` helper in `test/system/setup_wizard_test.rb`).
- **Lint:** `bin/rubocop` (whole repo clean), `bin/brakeman -q --no-pager`, `bin/rails zeitwerk:check`.
- **Commits:** conventional, each ending with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never skip hooks.

## Review Focus

1. **Autosave racing itself.** An editor types in a block while an earlier save is still in flight. The later value must win; no request may overwrite a newer value with an older one. Pinned in Task 9, system test 7 ("autosave queue: a newer queued save wins over an in-flight one").
2. **A translated field edited in a non-default locale.** It must never overwrite the default locale's value, and untranslated fields must not change. Pinned in Task 7 (`test "saving in de leaves en untouched"`).
3. **Moving a page under its own descendant, or moving the root, via drag and drop.** The server rejects it with a visible message and the tree re-renders in its old order. Pinned in Task 3 (`test "an invalid move re-renders the tree unchanged with an error"`).
4. **Deleting a block while its card has unsaved or in-flight edits.** No 500 and no resurrected block. Pinned in Task 5 (`test "updating a deleted block answers gone"`: the PATCH after destroy returns 410 with a status message).
5. **A stale `updated_at`** (the record was changed by MCP or another tab). The save still applies and the status shows the warning. Pinned in Task 4 (`test "a stale base still saves and warns"`).

`Admin::BaseController`:

```ruby
module Admin
  # Everything in CS Studio (cs-studio spec §4.1): signed-in only (inherited
  # Authentication), the admin layout, the :admin channel for services, and the
  # editing locale every screen reads.
  class BaseController < ApplicationController
    layout "admin"
    before_action { Current.channel = :admin }
    helper_method :admin_locale, :admin_url_options

    private

    # The language being edited: ?locale= when it's enabled, else the site's
    # default. Invalid or disabled codes fall back silently (spec §8).
    def admin_locale
      @admin_locale ||= Locales.enabled?(params[:locale]) ? params[:locale].to_s : Locales.default
    end

    # Link params that keep the editing language across navigation.
    def admin_url_options
      admin_locale == Locales.default ? {} : { locale: admin_locale }
    end

    # Attachment point for roles/policies (sub-project 5). Permissive for now.
    def authorize!(_action, _record) = true
  end
end
```
