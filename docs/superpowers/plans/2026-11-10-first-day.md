# First day after 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four issues from the architecture review of 2026-10-31, in one pull request: a new site starts with one language (#142), the development seed shows every block type (#137), a contributor's first day needs no hand-typed prefix and no forgotten build (#135), and every environment variable the code reads is listed in one place, held by a test (#138).

**Architecture:** No new domain. One migration changes a column default only. The seed's showcase is a plain module in `db/seeds/`, loaded by `db/seeds.rb` in development and by its own test; it builds blocks from each type's declared sample through a shared helper in `ContentModel`, which `test/support/block_samples.rb` uses too. The variable list is a table in `docs/reference/hosting.md`, read by a guard in `test/lib/`.

**Tech Stack:** Rails 8.1, Minitest, Postgres 17 (libpq's `gssencmode`).
