# Security

Please do not report a vulnerability in a public issue.

Report it privately through GitHub instead: on this repository's **Security**
tab, press **Report a vulnerability**. Say what is affected, how to reproduce
it and what it lets someone do. You will get an answer, and a fix is released
as a new image of the CMS (see `docs/reference/hosting.md`, "How a site's image
is built").

Only the newest commit of `main` is supported: a site pins a commit id, and a
fix reaches it when the site moves to a newer one.
